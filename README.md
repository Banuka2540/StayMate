# StayMate

Web Based Student Accommodation finding Platform developed as a Community Project to help students find suitable accommodation near Sabaragamuwa University.

Main Modules in StayMate project: 


## Main Modules

| # | Module | Purpose |
|---:|---|---|
| 1 | User Authentication & Authorization | Secure registration, login, logout, password management, JWT authentication, and role-based access. |
| 2 | Student Management | Maintain student profiles, university details, student IDs, reservation and payment histories, saved payment methods, and notifications. |
| 3 | Hostel Provider Management | Support provider registration, provider profiles, hostel registration, verification, dashboards, and listing management. |
| 4 | Hostel & Room Management | Allow providers to create and maintain hostel and room information, images, prices, facilities, and availability. |
| 5 | Hostel Search & Discovery | Help students find accommodation using search and filters, view listing details, and locate hostels on a map. |
| 6 | Reservation Management | Support room selection, move-in dates, reservations, advance payments, confirmations, cancellations, and reservation history. |
| 7 | Payment Management | Manage payment methods, advance and monthly rental payments, confirmations, payment status, history, and transaction records. |
| 8 | Administration | Provide administrative controls for users, providers, listings, reported listings, reservations, and payments. |
| 9 | Notification & Reporting | Send reservation, payment, reminder, and listing-approval notifications, and provide basic system reports. |
